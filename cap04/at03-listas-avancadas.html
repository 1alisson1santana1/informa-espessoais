Guias e Mapas de Tecnologias Web

Seção 1 — Roteiro de estudos

  1. Entender a arquitetura Cliente-Servidor
    1. Protocolo HTTP/HTTPS
    2. Requisições e respostas
  2. Dominar a estrutura de páginas
    1. Tags semânticas do HTML5
    2. Acessibilidade digital
  3. Estilizar componentes de interface
    1. Seletores CSS e especificidade
    2. Layouts com Flexbox e Grid

Após consolidar a base de marcação e estilização, entramos na fase de programação lógica e dinamismo da aplicação:

  1. Aprender lógica com JavaScript
    1. Manipulação do DOM
    2. Consumo de APIs assíncronas (Fetch)
  2. Trabalhar com ferramentas de build
    1. Gerenciadores de pacotes (NPM/Yarn)
    2. Versionamento com Git e GitHub
  3. Explorar Frameworks Modernos
    1. Componentização e estados
    2. Roteamento no ecossistema SPA

Seção 2 — Ranking de tecnologias

  1. HTML5: A espinha dorsal da web. Sem ela, nenhuma aplicação ou estilo pode ser renderizado e estruturado de forma acessível.

  2. CSS3: Crucial para design, responsividade e experiência visual do usuário em múltiplos dispositivos.

  3. JavaScript: Fornece a inteligência e o dinamismo necessário para criar interfaces ricas e interativas.

  4. SQL: Fundamental para se comunicar com bancos de dados relacionais e garantir a persistência das informações.

  5. Git: Essencial para o trabalho em equipe, controle de versões de código e segurança no fluxo de desenvolvimento.

Seção 3 — Glossário de termos técnicos

HTML
Linguagem de marcação utilizada para estruturar e dar significado ao conteúdo das páginas web.
Documento de texto interpretado nativamente pelos navegadores para renderizar interfaces gráficas.
API
Conjunto de rotinas e padrões de programação que permitem a comunicação e integração de dados entre sistemas distintos.
Mecanismo que expõe serviços de um backend de forma controlada e segura para consumo do frontend.
URL
Endereço Web
Cadeia de caracteres padronizada que aponta a localização exata de um recurso disponível na internet.
DOM
Árvore do Documento
Representação em memória estruturada em nós que permite scripts lerem e alterarem dinamicamente elementos HTML.
CSS
Mecanismo para adicionar estilos como cores, fontes e espaçamentos a documentos web.
JavaScript
Linguagem de programação de alto nível que roda do lado do cliente para prover comportamento dinâmico.
HTTP
Protocolo de transferência que dita as regras de comunicação entre clientes (navegadores) e servidores.
DNS
Sistema que traduz nomes de domínios amigáveis em endereços de IP legíveis por máquinas.
