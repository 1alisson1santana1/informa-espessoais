3. Glossário Técnico

API (Application Programming Interface)
Conjunto de definições e protocolos usado para integração entre sistemas, permitindo que diferentes softwares se comuniquem.
DOM (Document Object Model)
Estrutura em árvore que representa o documento HTML, permitindo que linguagens como JavaScript manipulem elementos, atributos e estilos.
Responsividade
Técnica de desenvolvimento que ajusta o layout automaticamente para diferentes tamanhos de tela (celular, tablet, desktop).
Framework
Conjunto de bibliotecas, padrões e ferramentas que fornece uma estrutura base para o desenvolvimento de aplicações.
Backend
Parte da aplicação responsável pela lógica de negócio, processamento de dados, autenticação e comunicação com banco de dados.
Frontend
Interface visual com a qual o usuário interage diretamente, geralmente construída com HTML, CSS e JavaScript.
RESTful
Estilo arquitetural para construção de APIs que utiliza métodos HTTP (GET, POST, PUT, DELETE) e princípios REST.
Webpack
Empacotador de módulos que gerencia dependências, otimiza e agrupa arquivos (JavaScript, CSS, imagens) para produção.
