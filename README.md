# Validação de Formulários com HTML e JavaScript

Este projeto foi construído para o laboratório do **Capítulo 15**, simulando um sistema de inscrição para novos estudantes de uma escola técnica.

##  Funcionalidades Implementadas
- **Estruturação Semântica:** Uso correto de fieldsets, labels associados e tipos de inputs modernos.
- **Validação Cruzada & Regex:** Validação estrita de formato de telefone `(82) 99999-9999` e verificação de idade mínima (16 anos).
